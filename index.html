เชื่อมต่อ Google Sheets & Google Drive

ท่านสามารถเปลี่ยน URL การดีพลอย Web App, Google Sheet และ โฟลเดอร์ Google Drive ได้ทันทีโดยไม่ต้องแก้โค้ด พร้อมระบบสร้างโครงสร้าง Sheet ให้อัตโนมัติ

1. Google Apps Script Web App URL (URL การดีพลอย) ยังไม่ได้ทดสอบ
URL จากการ Deploy: ทำให้ใช้งานได้ > การทำให้ใช้งานได้ใหม่ > เว็บแอปพลิเคชัน > สิทธิ์เข้าถึง: ทุกคน (Anyone)
2. Google Sheets (ฐานข้อมูลนักศึกษา)
ID ที่ใช้งาน: -
3. Google Drive (โฟลเดอร์จัดเก็บไฟล์เอกสาร)
ID ที่ใช้งาน: -
อย่าลืมตั้งค่าแชร์โฟลเดอร์เป็น "ทุกคนที่มีลิงก์มีสิทธิ์ดู (Anyone with link can view)" เพื่อให้แสดงรูป/PDF ได้
ขั้นตอนการย้ายหรือสร้างฐานข้อมูลใหม่ (คลิกเพื่อดูคำแนะนำ)
  1. สร้าง Google Sheet ใหม่: สร้าง Google Sheet ว่าง 1 ไฟล์ แล้วคัดลอกลิงก์หรือ ID มาวางในช่องด้านบน
  2. สร้างโฟลเดอร์ Google Drive ใหม่: สร้างโฟลเดอร์สำหรับเก็บเอกสาร ตั้งค่าแชร์เป็น "ทุกคนที่มีลิงก์" แล้วคัดลอกลิงก์หรือ ID มาวาง
  3. กดปุ่ม "ซิงค์ & ตั้งค่าโครงสร้าง Sheet อัตโนมัติ": ระบบจะสั่งให้ Google Apps Script สร้างคอลัมน์ ตรึงหัวตาราง ตั้งค่า Dropdown และเชื่อมโยงโฟลเดอร์ให้ทันทีโดยอัตโนมัติ!
  4. หากเปลี่ยนโปรเจกต์ Google Apps Script ใหม่ ให้นำโค้ดจาก GAS.txt ไปวาง แล้ว Deploy เป็น Web App นำ URL มาใส่ในช่องที่ 1
